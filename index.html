使用说明

这个 API 接口，是官方直连、中转站，还是上游被掉包？

输入任意 OpenAI 兼容 /v1、Anthropic 或 Gemini 接口基址，工具会从两根正交的轴给出带证据链与不确定性的报告： 轴 1「连接方式」判断你连的是官方还是第三方；轴 2「上游真伪」判断第三方上游给你的是不是真模型。 两者并列展示，绝不合并成一个分数。

  • 默认「指纹（免费）」档位不发送任何可能计费的请求；「真伪 / 完整」档位需要 API Key，并在发请求前展示请求数与 token 预估、要求你显式勾选确认。
  • 「检测无效」与「未达标」严格区分：Key 失效 / 余额不足 / 模型不存在只显示灰色的「检测无效」，绝不显示误导性的低分。
  • 不硬编码中转站黑名单，只做特征判定；「Cloudflare / 公共 CA / 非官方域名」一律视为中性证据。
  • 纯静态页面，无构建步骤，可直接托管在 GitHub Pages；也支持本地代理模式读取真实响应头与 TLS 证书。

怎么用 / 两轴怎么读 / 为什么有局限 / 如何跑本地代理

① 怎么用

  1. 填入 API 基址（例如 https://api.example.com/v1）。
  2. 选择检测深度：想免费只看连接方式就选「指纹」；想验证上游真假（或两者都看）就选「真伪 / 完整」，此时必须填 API Key 与模型。
  3. 选择需要 Key 的档位后，先阅读「费用确认」里的请求数与 token 预估，勾选确认后按钮才会亮起。
  4. 点击「开始检测」，报告分为轴 1 连接方式与轴 2 上游真伪两张卡片，互不合并。
  5. 用「复制完整报告」或「下载 report.json」保存结论，便于对照与复核。

② 为什么浏览器模式有局限

  • CORS 会过滤响应头：浏览器只能看到白名单内的少数头，检测所需的官方/网关特征头往往看不到。
  • 读不到 TLS 证书：浏览器不暴露对端证书链与签发者，而这是 TSL 层最有价值的证据之一。
  • 看不到真实网络层信息：IP、跳数、CDN 归属等都不可见。
  • 因此浏览器模式证据强度通常偏低，容易被判为「证据不足 / 无法判定」——这是保守设计，不是工具失效。
  • 官方响应头在反向代理下会被原样透传，因此仅凭响应头判定直连是不可靠的；本项目以域名身份作为直连的核心依据。

③ 如何跑本地代理

  1. 在仓库根目录执行 node proxy/server.mjs（默认监听 127.0.0.1:8787）。
  2. 页面右上角切换到「本地代理」模式，代理地址保持默认即可。
  3. 代理会代替浏览器发起请求并回显真实响应头，同时用 GET /inspect 读取对端 TLS 证书。
  4. 代理默认拒绝内网 / 环回目标，并带超时、体积上限与跳数校验；详见仓库 proxy/README.md。
  5. 本地验证静态页面：访问 http://127.0.0.1:8787/ 即可（等价 GitHub Pages 根目录）。

④ 结果怎么读：两根正交的轴

  • 轴 1 连接方式：我连的是官方还是第三方？看 score（越高越像中转站）与 evidenceStrength（低于 40% 一律判为「无法判定」）。
  • 轴 2 上游真伪：第三方上游给的是不是真模型？看真伪评分、检测器表格与严重问题。阈值：85 优秀 / 70 通过 / 50 基本合格，低于 50 未达标。
  • 两根轴严禁合并：中转站也可能诚实转发真模型；官方直连则无需真伪检测。
  • skip / error 不是失败：被跳过或执行出错的检测器不计入加权分母，不会被当作 0 分拉低总分；只有「未通过」才是低分。
  • 检测无效 ≠ 未达标：Key 失效、余额不足、模型不存在、无可用渠道时，真伪轴整块显示灰色「检测无效」并提示换 Key / 换模型，不会显示低分。
  • 请把报告当作线索集合，并用账单主体、官方文档交叉验证；本项目不提供「确定是 / 不是」的结论。

⑤ 两轴组合怎么解读

  • 中转站 + 真伪通过 → 「中转站，但上游是真模型 → 可用」。仍建议留意计费、隐私与稳定性。
  • 中转站 + 真伪未达标 → 「中转站，且上游疑似被掉包 → 建议更换」，停止在该站付费。
  • 中转站 + 基本合格 → 「中转站，存在可疑迹象 → 谨慎使用」，不要用于重要或高金额任务。
  • 官方直连 → 真伪轴显示「官方直连，无需真伪检测」。
  • 连接方式无法判定 → 「连接方式无法判定，真伪结果单独参考」，两轴互不替代。

⑥ 费用、Key 与隐私

  • 「指纹」档位只发只读探测，默认不产生费用。
  • 「真伪 / 完整」档位会向目标发送真实对话请求，会产生费用；发请求前必须展示 estimateCost() 的预估并显式勾选。
  • Key 仅存在于浏览器内存与请求头，不会上传到任何第三方服务器；默认不写 localStorage。
  • 只有勾选「保存密钥到本机」才会落盘；随时可以点击「立即清除 Key」。
  • 历史记录只存主机名、模型、两轴结论与时间，绝不存 Key，也绝不存报告正文。
